복무·출장·초과근무 신청 칸만 채워 줘요

나이스 ▾를 펼치면 주황색 ✎ 칸은 «신청»(나이스 칸을 채워 줌), 초록 칸은 «화면 열기»예요. 채우기가 끝나면 알림 창이 떠요.

  1. «2. 나이스 ▾» → «복무 신청» / «출장 신청» / «초과근무 신청»을 누르세요.
  2. 종류·날짜·시각과 사유(출장지·목적, 할 일)를 적고 [나이스에 채우기]를 누르세요. 시각은 1300처럼 적어도 돼요.
  3. 나이스 신청 창에 칸이 채워져 있어요. 일수·시간 합이 맞는지 보고, 결재선을 고른 뒤 [승인요청]은 직접 누르세요.

위젯은 칸만 채우고 승인요청(상신)은 누르지 않아요.
· 복무: 병원 진료면 «병조퇴·병외출·병지각» · 끝 날짜를 다른 날로 고르면 매일 같은 시각(나이스 «일반복», 주말은 나이스가 뺌)
· 출장: 같은 시도교육청 안이면 관내, 밖이면 관외 · 하루 안의 몇 시간짜리는 «0일 ○시간»으로 맞춰 넣어요
· 초과근무: 달력에서 여러 날을 고르면 한 번에 (나이스 [행추가]로 날마다 한 줄) · 토·일은 «휴일»에 저절로 체크 (공휴일은 «고른 날 모두 휴일») · 휴일 초과근무는 전날 18시 전에 올려야 사전신청으로 인정돼요

🟢 초록색 업무용 크롬

위젯은 평소 쓰시는 크롬이 아니라 위젯 전용 «업무용 크롬»을 따로 띄워요. 창 위쪽이 초록색이고, 작업표시줄에 마우스를 올리면 «업무용 크롬 (위젯)»이라고 보여요.

  • 업무포털·나이스·에듀파인은 초록색 업무용 크롬에서 쓰세요. 뉴스·유튜브 같은 일반 인터넷은 평소 크롬에서.
  • 따로 떼어 두는 이유: 크롬이 보안을 위해 평소 크롬은 프로그램이 조종하지 못하게 막아요. 그래서 분리하는 편이 더 안전해요.
  • 즐겨찾기가 필요하면 업무용 크롬 오른쪽 위에서 구글 계정으로 로그인하면 평소 즐겨찾기가 들어와요. (안 해도 위젯은 잘 돼요)

🔢 결재대기·기관접수 숫자 칸
칸하는 일
에듀파인 결재대기결재대기 건수를 30분마다 읽어요. 누르면 결재대기함이 열려요 (결재·반려는 안 함). 숫자만 지금 다시 읽으려면 오른쪽 클릭. 결재대기가 있으면 노란 음영, 긴급이면 붉은 음영이 은은하게 반짝여요 (⚙ → 자동 실행·알림 → 결재대기 반짝임으로 끌 수 있어요). 새로 오면 화면 가운데에 «업무위젯 알림» 창이 떠요 (⚙ → 자동 실행·알림 → 결재대기 알림으로 끌 수 있어요).
교데통 기관접수교육행정데이터통합관리 «데이터취합 › 제출자료 › 기관접수대기» 건수를 30분마다 읽어요. 누르면 그 화면을 열어요 (접수·제출은 안 함).
숫자는 업무포털에 로그인돼 있어야 읽혀요. 위젯을 켠 뒤 «1. 업무포털»을 한 번 눌러 두세요. 안 돼 있으면 칸에 --만 떠요.
🎨 화면 바꾸기 (시계·투명도·크기·자동 접기·업무전용 칸·가벼운 모드)
  • ⚙ → 화면 → 시계 카드 보이기 : 날짜·요일·시·분·초 카드를 하나씩 켜고 끄기. 끈 카드는 빠지고 남은 카드끼리 붙어요.
  • ⚙ → 화면 → 투명도 : 위젯을 흐리게 (30%~100%).
  • ⚙ → 화면 → 위젯 크기 : 작게(85%)·보통·크게(120%). 바꾸면 위젯이 한 번 다시 켜져요.
  • ⚙ → 화면 → 자동 접기 : 1·3·5·10·30분, 또는 직접 정하기…로 적은 시간(1~600분) 동안 위젯을 안 쓰면 오른쪽 위 모서리에 작은 둥근 단추로 접혀요. 단추를 누르면 다시 펼쳐지고, 끌면 옮겨져요. 결재대기가 있으면 단추에 건수가 보여요. 펼침 줄·신청 창이 떠 있거나 마우스가 위젯 위에 있으면 접히지 않아요. 처음에는 꺼져 있고, 지금 접기로 바로 접을 수도 있어요.
  • ⚙ → 화면 → 업무전용 칸 쓰기 : 끄면 예전 배치로 돌아가요 (월·일 따로, 아랫줄 끝에 결재대기·기관접수). 바꾸면 위젯이 한 번 다시 켜지고, 넣어 둔 업무전용 칸 목록은 그대로 남아요.
  • ⚙ → 화면 → 가벼운 모드 : 느린 PC용이에요. 시계는 넘김 그림 없이 숫자로, 결재대기 반짝임과 서서히 사라지기는 꺼지고, 결재대기·기관접수 숫자는 자동으로 읽지 않고 칸을 오른쪽 클릭할 때만 읽어요. 바꾸면 위젯이 한 번 다시 켜져요. 메모리 6GB 미만이거나 코어 2개 이하인 PC에서는 처음 켤 때 한 번 물어봐요.
  • ⚙ → 화면 → 메모 보이기 : 위젯의 날짜 카드들 위에 메모 줄이 생겨요. ＋ 새 메모를 누르면 포스트잇 창이 떠요. 메모 줄의 이름표를 누르면 그 포스트잇이 열리고, 다시 누르면 닫혀요(펼침 칸처럼).
    • 포스트잇 위쪽: 제목 · 체크리스트 / 메모장 바꾸기 · 🎨 색·투명도 · ⏰ 알림 · 🗑 지우기(한 번 더 물어봐요) · ✕ 닫기. 맨 위 빈 줄을 끌면 옮겨져요(제목칸이 눌리지 않아요).
    • 🎨 색·투명도: 배경색을 8가지(노랑·분홍·연두·하늘·보라·주황·흰색·회색) 중에서 고르고, 슬라이더로 투명도를 조절해요. 메모마다 따로 기억해요.
    • 글씨 크기: 🎨 창의 슬라이더로 8~50까지(처음 10), 또는 글 위에서 Ctrl 을 누른 채 마우스 휠을 돌려 키우고 줄여요. 메모마다 따로 기억해요.
    • 크기 조절: 포스트잇의 가장자리나 모서리를 끌면 위·아래·옆·대각선 어디로든 키우고 줄일 수 있어요. 크기와 위치는 기억해요.
    • 메모장: 여러 줄을 자유롭게 적어요. 체크리스트: 아래 칸에 적고 Enter 로 항목을 넣고, 끝난 건 체크해요.
    • ⏰ 알림: «15:30», «내일 9:00», «11/26 15:30»처럼 적거나 «10분 뒤» 단추를 누르면, 그 시각에 화면 가운데에 «업무위젯 알림» 창이 뜨고 포스트잇이 열려요. 포스트잇에는 «18:01(4분 후)에 알려드려요»처럼 남은 시간이 보여요. 위젯이 켜져 있어야 알려 드려요.

🤖 AI 사용량 링 (Claude·Codex·agy 를 쓰는 분만)

이 PC에 Claude Code·Codex·agy(Antigravity) 중 하나라도 깔려 있을 때만 ⚙ → AI 사용량 메뉴가 보여요. 처음에는 꺼져 있으니 안 쓰시는 분은 신경 쓰지 않으셔도 돼요.

  • ⚙ → AI 사용량 → AI 사용량 보이기 : 켜면 위젯 위쪽에 링이 한 줄 생겨요. 아래에서 위젯 위쪽 줄에 크게 / 제목 줄에 작게를 고를 수 있고, 보고 싶은 도구만 체크하면 돼요.
  • 바깥 큰 링 = 5시간 사용량, 가운데 숫자도 5시간 %예요. 안쪽 작은 링 = 주간 사용량(보라)이에요. 옆 글자는 초기화까지 남은 시간이에요.
  • 색: 초록은 여유, 분홍은 70% 넘음, 빨강은 90% 넘음(주간 링도 90% 넘으면 빨강).
  • 지금 속도로 초기화 전에 다 쓸 것 같으면 옆 글자가 빨간 «0:40 뒤 바닥»으로 바뀌어요. 켠 뒤 몇 분 지나야 계산돼요.
  • Claude가 90%를 넘거나 곧 바닥나면, 여유가 가장 많은 Codex·agy 옆에 초록 «▶ 다음»이 붙어요.
  • 링에 마우스를 올리면 주간·모델별 사용량이 자세히 나오고, 링을 누르면 새로 읽어요.
  • ⚙ → AI 사용량 → Claude 상태 색·승인 대기 알림 : Claude가 작업 중이면 주황, 승인을 기다리면 파랑 링이 돼요. 승인 대기가 3분 넘으면 화면 가운데에 알림 창이 뜨고, 그때 Claude 링을 누르면 Claude 창이 앞으로 와요. (Claude Code 설정에 위젯용 훅을 넣어 둔 PC에서만 동작해요.)
  • ⚙ → AI 사용량 → Claude 작업 끝 알림 : Claude 작업이 5분 넘게 걸렸다가 끝나면 화면 가운데에 알림 창이 떠요. Claude 창을 보고 있을 때는 띄우지 않아요. (위 훅이 있는 PC에서만)
  • ⚙ → AI 사용량 → 초기화 알림 : 90% 넘게 썼던 도구가 초기화되어 다시 쓸 수 있게 되면 «다시 써도 돼요» 알림이 떠요.
  • 사용량은 이 PC에 저장된 각 도구의 로그인 정보로 그 회사 서버에 직접 물어봐요. 업무위젯은 그 정보를 다른 곳에 보내거나 저장하지 않아요.
🪟 위젯 닫기·다시 열기·자동 실행
  • 오른쪽 위 ✕는 끄는 게 아니라 위젯을 작은 둥근 단추로 접어요. 단추를 누르면 다시 펼쳐지고, 단추를 오른쪽 클릭하면 펼치기·닫기(트레이로)·종료를 고를 수 있어요.
  • 그 옆 –는 시스템 트레이(작업표시줄 오른쪽 아래)로 내려 보내요. 트레이의 «업무위젯» 아이콘을 누르면 다시 나와요. 안 보이면 ^를 눌러 숨겨진 아이콘을 펼쳐 보세요.
  • 트레이 아이콘 오른쪽 클릭 → «열기 / 윈도우 시작할 때 자동 실행 / 위젯 완전 종료».
  • ⚙ → 자동 실행·알림 → 윈도우 시작할 때 자동 실행 으로도 켜고 끌 수 있어요.
  • 위젯이 안 보이면 바탕화면 «업무위젯»을 한 번 더 누르면 앞으로 나와요.
