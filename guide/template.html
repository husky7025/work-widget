복무·출장·초과근무 신청 칸만 채워 줘요

나이스 ▾를 펼치면 주황색 ✎ 칸은 «신청»(나이스 칸을 채워 줌), 초록 칸은 «화면 열기»예요. 채우기가 끝나면 알림 창이 떠요.

  1. «2. 나이스 ▾» → «복무 신청» / «출장 신청» / «초과근무 신청»을 누르세요.
  2. 종류·날짜·시각과 사유(출장지·목적, 할 일)를 적고 [나이스에 채우기]를 누르세요. 시각은 1300처럼 적어도 돼요.
  3. 나이스 신청 창에 칸이 채워져 있어요. 일수·시간 합이 맞는지 보고, 결재선을 고른 뒤 [승인요청]은 직접 누르세요.

위젯은 칸만 채우고 승인요청(상신)은 누르지 않아요.
· 복무: 병원 진료면 «병조퇴·병외출·병지각» · 끝 날짜를 다른 날로 고르면 매일 같은 시각(나이스 «일반복», 주말은 나이스가 뺌)
· 출장: 같은 시도교육청 안이면 관내, 밖이면 관외 · 하루 안의 몇 시간짜리는 «0일 ○시간»으로 맞춰 넣어요
· 초과근무: 달력에서 여러 날을 고르면 한 번에 (나이스 [행추가]로 날마다 한 줄) · 토·일은 «휴일»에 저절로 체크 (공휴일은 «고른 날 모두 휴일») · 휴일 초과근무는 전날 18시 전에 올려야 사전신청으로 인정돼요

🟢 초록색 업무용 크롬

위젯은 평소 쓰시는 크롬이 아니라 위젯 전용 «업무용 크롬»을 따로 띄워요. 창 위쪽이 초록색이고, 작업표시줄에 마우스를 올리면 «업무용 크롬 (위젯)»이라고 보여요.

  • 업무포털·나이스·에듀파인은 초록색 업무용 크롬에서 쓰세요. 뉴스·유튜브 같은 일반 인터넷은 평소 크롬에서.
  • 따로 떼어 두는 이유: 크롬이 보안을 위해 평소 크롬은 프로그램이 조종하지 못하게 막아요. 그래서 분리하는 편이 더 안전해요.
  • 즐겨찾기가 필요하면 업무용 크롬 오른쪽 위에서 구글 계정으로 로그인하면 평소 즐겨찾기가 들어와요. (안 해도 위젯은 잘 돼요)
▾ 펼침 칸 메뉴 바꾸기 (나이스·에듀파인·업무전용)

⚙ → 펼침 메뉴 고르기 에서 칸마다 넣을 메뉴를 직접 고를 수 있어요.

  1. 처음 한 번 [내 메뉴 읽어오기]를 누르면 나이스·에듀파인에 로그인해서 선생님 계정의 메뉴 목록을 읽어 와요 (1분쯤, 화면은 옮기지 않아요).
  2. 위 탭에서 나이스 / 에듀파인 / 업무전용을 고르고, 왼쪽 목록에서 누르면 넣기·빼기, 오른쪽에서 순서 바꾸기.
  3. [＋ 내 프로그램 넣기]로 프로그램·파일·폴더·웹 주소도 어느 칸에나 넣을 수 있어요.
  4. [저장]. 칸마다 12개까지 넣을 수 있어요.
  • 나이스 신청서나 에듀파인 팝업을 쓰는 중이면 화면을 옮기지 않고 «열린 창을 마친 뒤 다시 눌러 주세요»라고만 알려 줘요.
  • 이미 열어 둔 화면을 다시 누르면 새로 열지 않고 그 탭으로 돌아가요.
  • 위젯이 화면 아래쪽에 있어 공간이 모자라면 위쪽으로 펼쳐져요.
🔢 결재대기·기관접수 숫자 칸
칸하는 일
에듀파인 결재대기결재대기 건수를 30분마다 읽어요. 누르면 결재대기함이 열려요 (결재·반려는 안 함). 숫자만 지금 다시 읽으려면 오른쪽 클릭. 결재대기가 있으면 노란 음영, 긴급이면 붉은 음영이 은은하게 반짝여요 (⚙ → 자동 실행·알림 → 결재대기 반짝임으로 끌 수 있어요). 새로 오면 윈도우 알림이 떠요 (⚙ → 자동 실행·알림 → 결재대기 알림으로 끌 수 있어요).
교데통 기관접수교육행정데이터통합관리 «데이터취합 › 제출자료 › 기관접수대기» 건수를 30분마다 읽어요. 누르면 그 화면을 열어요 (접수·제출은 안 함).
숫자는 업무포털에 로그인돼 있어야 읽혀요. 위젯을 켠 뒤 «1. 업무포털»을 한 번 눌러 두세요. 안 돼 있으면 칸에 --만 떠요.
🎨 화면 바꾸기 (시계·투명도·크기·자동 접기·업무전용 칸)
  • ⚙ → 화면 → 시계 카드 보이기 : 날짜·요일·시·분·초 카드를 하나씩 켜고 끄기. 끈 카드는 빠지고 남은 카드끼리 붙어요.
  • ⚙ → 화면 → 투명도 : 위젯을 흐리게 (30%~100%).
  • ⚙ → 화면 → 위젯 크기 : 작게(85%)·보통·크게(120%). 바꾸면 위젯이 한 번 다시 켜져요.
  • ⚙ → 화면 → 자동 접기 : 1·3·5·10·30분, 또는 직접 정하기…로 적은 시간(1~600분) 동안 위젯을 안 쓰면 오른쪽 위 모서리에 작은 둥근 단추로 접혀요. 단추를 누르면 다시 펼쳐지고, 끌면 옮겨져요. 결재대기가 있으면 단추에 건수가 보여요. 펼침 줄·신청 창이 떠 있거나 마우스가 위젯 위에 있으면 접히지 않아요. 처음에는 꺼져 있고, 지금 접기로 바로 접을 수도 있어요.
  • ⚙ → 화면 → 업무전용 칸 쓰기 : 끄면 예전 배치로 돌아가요 (월·일 따로, 아랫줄 끝에 결재대기·기관접수). 바꾸면 위젯이 한 번 다시 켜지고, 넣어 둔 업무전용 칸 목록은 그대로 남아요.
  • 위젯은 마지막으로 놓은 자리를 기억해요. 제목 줄이나 빈 곳을 끌어 옮기세요.
🪟 위젯 닫기·다시 열기·자동 실행
  • 오른쪽 위 ✕는 끄는 게 아니라 위젯을 작은 둥근 단추로 접어요. 단추를 누르면 다시 펼쳐지고, 단추를 오른쪽 클릭하면 펼치기·닫기(트레이로)·종료를 고를 수 있어요.
  • 그 옆 –는 시스템 트레이(작업표시줄 오른쪽 아래)로 내려 보내요. 트레이의 «업무위젯» 아이콘을 누르면 다시 나와요. 안 보이면 ^를 눌러 숨겨진 아이콘을 펼쳐 보세요.
  • 트레이 아이콘 오른쪽 클릭 → «열기 / 윈도우 시작할 때 자동 실행 / 위젯 완전 종료».
  • ⚙ → 자동 실행·알림 → 윈도우 시작할 때 자동 실행 으로도 켜고 끌 수 있어요.
  • 위젯이 안 보이면 바탕화면 «업무위젯»을 한 번 더 누르면 앞으로 나와요.

로그인·인증서 창이 안 뜸나이스 인증서 프로그램이 돌고 있는지 확인하고, 컴퓨터를 다시 켜 보세요.
«중복로그인…» 문구평소 쓰는 크롬에서 같은 계정을 로그아웃하고 다시 누르세요.
학교 밖에서 안 열림학교 업무망(랜선)에서 쓰세요.
결재대기 칸이 --업무포털이 열려 있는지(1. 업무포털) 확인하세요. 칸을 오른쪽 클릭하면 이유가 보여요.
기관접수 칸이 --«1. 업무포털»을 누른 뒤 기관접수 칸을 한 번 눌러 보세요. 기관접수대기 숫자는 대전에서만 시험했어요.
품의등록이 에듀파인 첫 화면에서 멈춤위젯 아래 문구를 알려 주세요. 크롬에서 «업무관리» › «학교회계» › 사업담당 › 품의/정산 › 품의등록을 눌러도 같은 화면이에요.
내부기안이 서식을 못 찾음위젯에 뜨는 «비슷한 서식 이름»을 적어서 알려 주세요.
업무전용 칸이 «파일이 없어요»파일을 옮겼거나 지웠어요. ⚙ → 펼침 메뉴 고르기에서 빼고 다시 넣으세요.
설치 창에 «설치가 끝나지 않았어요»창에 적힌 파일(업무위젯_설치기록.txt)을 알려 주신 분께 보내 주세요.
